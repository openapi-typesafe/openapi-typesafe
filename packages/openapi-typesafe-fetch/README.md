# openapi-typesafe-fetch

A type-safe `fetch` client for types generated by [`openapi-typesafe`](../openapi-typesafe). About 11 kB minified
(4 kB gzipped), no runtime dependencies, works in browsers, Node.js, Bun and Deno, and with React, Vue, Svelte or plain JavaScript.

A maintained, drop-in successor to `openapi-fetch` (see the [repository README](../../README.md)).

> **Release candidate.** The current version is a 1.0.0 release candidate (`1.0.0-rc.N`);
> names and output can still change before 1.0.0.

## Setup

```sh
npm i openapi-typesafe-fetch
npm i -D openapi-typesafe typescript
npx openapi-typesafe ./openapi.yaml -o ./src/api/schema.d.ts
```

## Usage

```ts
import createClient from "openapi-typesafe-fetch";
import type { paths } from "./api/schema";

const client = createClient<paths>({ baseUrl: "https://api.example.com/v1/" });

const {
  data, // present on a 2xx response
  error, // present on a response that is not 2xx
} = await client.GET("/posts/{post_id}", {
  params: { path: { post_id: "123" } },
});

await client.PUT("/posts", {
  body: { title: "My new post" },
});
```

URLs, parameters, request bodies and responses are all checked against the schema, with no generics or type
assertions in your code. `GET()`, `PUT()`, `POST()` and the other methods are thin wrappers around the native
[Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API); you can pass your own `fetch`.

Also included: middleware (`client.use()` / `client.eject()`), custom query, path and body serializers, `parseAs`
for non-JSON responses, and a path-based client (`createPathBasedClient`).

## Migrating from openapi-fetch

```diff
- import createClient from "openapi-fetch";
+ import createClient from "openapi-typesafe-fetch";
```

## Versioning

Semantic versioning from 1.0.0, with one version for all openapi-typesafe packages. What the
version promises, and what may grow in a minor release, is listed under
[Versioning](https://github.com/openapi-typesafe/openapi-typesafe/blob/main/docs/compatibility.md#versioning).
